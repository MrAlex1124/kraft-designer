# Kraft Designer — contribution guidelines

This repository is a standalone, general-purpose CAD application.

- Contributions must deliver generic CAD editing, geometry, import/export, UI, localization, documentation, testing or deployment value.
- Do not commit secrets, credentials, production configuration, personal information, private hostnames, internal network topology, customer data or business-specific code.
- Keep the app independently operable. Do not couple CAD functionality to proprietary services, checkout, pricing or order handling.
- Use placeholders rather than real domains or infrastructure identifiers in examples.
- Keep licensed upstream notices and the AGPL-3.0-only license intact.
- Review staged diffs and Git history before pushing to public branches.
